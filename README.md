# Telegram-бот сбора заявок на пилотное тестирование «РИТМ»

Бот разработан на стеке **Python 3.10+** и **aiogram 3.x** с использованием машины состояний (FSM) и локальной базы данных **SQLite** (`aiosqlite`).

---

## 1. Регистрация и настройка бота в @BotFather

1. Откройте диалог с официальным ботом [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду:
   ```text
   /newbot
   ```
3. Введите **отображаемое имя бота**, например:
   ```text
   Ритм | Заявки на пилот
   ```
4. Введите **юзернейм бота** (должен оканчиваться на `bot`), например:
   ```text
   ritm_pilot_bot
   ```
5. `@BotFather` пришлет сообщение с **HTTP API токеном** вида:
   `7123456789:AAHk...`
   *Скопируйте этот токен.*

### Настройка описания и команд (через @BotFather):
1. **Команды бота (`/setcommands`):**
   Отправьте `@BotFather` команду `/setcommands`, выберите вашего бота и отправьте список:
   ```text
   start - Главное меню и регистрация
   apply - Заполнить заявку на пилот
   cancel - Отменить текущее заполнение
   about - Информация о проекте Ритм
   help - Справка по боту
   ```
2. **Описание бота при открытии (`/setdescription`):**
   ```text
   Telegram-бот для подачи заявок учебных групп вузов и колледжей на участие в пилотном тестировании системы «РИТМ» (20–26 ноября 2026).
   ```
3. **О себе (`/setabouttext`):**
   ```text
   «РИТМ» — автопилот расписания и переклички для старост. Регистрация пилотных групп.
   ```

## 2. Установка и запуск бота

### Шаг 1. Настройка окружения
В папке `pilot_bot` создайте файл `.env` (на основе `.env.example`):

```env
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_IDS=ваш_telegram_id
```

> **Как узнать свой Telegram ID?**  
> Откройте бота [@userinfobot](https://t.me/userinfobot) в Telegram — он пришлет числовой ID вашего профиля (например, `123456789`).

### Шаг 2. Запуск бота
В терминале проекта выполните:

```powershell
# Активация виртуального окружения
& "d:\Проект тг\.venv\Scripts\Activate.ps1"

# Запуск
python "d:\Проект тг\pilot_bot\main.py"
```

## 3. Сценарий работы бота

1. **Приветствие (`/start`):** объяснение задач «Ритма» и сроков пилота (20–26 ноября 2026).
2. **Шаг 1:** Выбор роли кнопками (Староста / Замстаросты / Куратор / Студент).
3. **Шаг 2:** ФИО или Имя Фамилия заявителя.
4. **Шаг 3:** Учебное заведение (вуз или колледж).
5. **Шаг 4:** Номер/шифр группы и курс.
6. **Шаг 5:** Численность группы (проверка на число).
7. **Шаг 6:** Описание текущей рутины (как сейчас получают отмены и ведут учет).
8. **Шаг 7:** Контакт для связи (кнопка Telegram «Поделиться контактом» или ручной ввод).
9. **Подтверждение:** Итоговая сводка с кнопками «Подтвердить и отправить» / «Заполнить заново».
10. **Уведомление:**
    - Заявителю: подтверждение с номером заявки `#{id}`.
    - Администратору: мгновенная карточка заявки в Telegram со ссылкой на профиль заявителя.
    - База данных: сохранение в `applications.db` (SQLite).
